# PrimeTime four-screen digital menu

This is a static GitHub Pages website for four independent 16:9 restaurant displays. Nothing requires swiping or customer interaction.

## Start here

Open `START-HERE.html` to see four large screen choices. You can then open each display directly:

- `Screen-1-Donairs.html`
- `Screen-2-Poutines.html`
- `Screen-3-Burgers-Sandwiches.html`
- `Screen-4-Rice-Kids-Desserts.html`

The original `index.html` contains all four designs and selects one using the `?screen=` part of the URL. That is why opening `index.html` by itself shows Screen 1.

After GitHub Pages is enabled, use one direct page on each TV:

- `https://YOUR-USERNAME.github.io/YOUR-REPO/Screen-1-Donairs.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPO/Screen-2-Poutines.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPO/Screen-3-Burgers-Sandwiches.html`
- `https://YOUR-USERNAME.github.io/YOUR-REPO/Screen-4-Rice-Kids-Desserts.html`

## Publish

1. Upload every file and the `assets` folder to the root of a GitHub repository.
2. Open **Settings → Pages** in that repository.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Open the assigned URL on each display and use full-screen mode.

Designed for 1920×1080 displays. The menu remains fixed; only small food, steam and dessert accents animate.

Before using it in-store, confirm every price with the restaurant owner. Prices were taken from the supplied menu references and can vary by location.

Food photography and the logo are from the official PrimeTime Donair & Poutine website: https://www.primetimedonair.com/
